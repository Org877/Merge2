# Lenguajes y cadenas
- Alfabeto Σ: conjunto finito de símbolos. Cadena: secuencia finita de símbolos; ε es la cadena vacía.
- Lenguaje: conjunto de cadenas sobre Σ. Σ* es el conjunto de todas las cadenas posibles.
- Operaciones: unión (L ∪ M), intersección, diferencia, concatenación L·M = {xy | x∈L, y∈M}, potencia L^n, clausura de Kleene L* = ⋃ L^i (i≥0), positiva L+ (i≥1), inversa y complemento (respecto a Σ*).
- Error común: confundir ∅ (lenguaje vacío) con {ε} (lenguaje con solo la cadena vacía).
- L^0 = {ε}. Σ* es infinito, por eso aquí se genera hasta una longitud máxima k.
